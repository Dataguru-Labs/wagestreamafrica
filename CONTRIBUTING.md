# Contributing to WageStream Africa 💸

We welcome contributors of all experience levels!

## 🐣 Good First Issues (Beginners)
- Improve the README
- Add UI components for worker dashboard
- Write tests for existing functions
- Translate documentation to Yoruba, Igbo, or Hausa

## 🔧 Intermediate Issues
- Build employer salary float deposit system
- Create worker earnings dashboard
- Implement USDC payment integration on Stellar
- Add worker credit score calculation

## 📋 How to Contribute
1. Fork this repo
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Push and open a Pull Request

## 💬 Code of Conduct
Be kind. Be respectful. We are building for Africa. 🌍

## 🙋 Questions?
Open an issue and we will get back to you!
